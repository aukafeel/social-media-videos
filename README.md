# social-media-videos

Finished videos for scheduled social posts (published via Metricool).
Each channel has its own folder:

- `story-behind-the-quote/`: Story Behind the Quote
- `success-code/`: The Success Code
- `creator-and-his-creation/`: Creator and His Creation

This repo is public so Metricool can fetch the files by their raw URL:
`https://raw.githubusercontent.com/aukafeel/social-media-videos/main/<folder>/<file>.mp4`
